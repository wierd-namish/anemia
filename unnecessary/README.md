# Archived Historical & Non-Runtime Materials

This directory contains historical, obsolete, or non-runtime materials retained solely for reference, audit provenance, and development history.

## Important Version Control & Data Policy

> [!WARNING]
> This folder is strictly for lightweight historical scripts and text reports that are intentionally retained.
> Large generated model weights (`*.pth`), patient datasets (`Fingernails/`), credentials, cache files, and virtual environments must **never** be placed in Git, and remain excluded via `.gitignore`.

## Structure

```
unnecessary/
├── README.md               <- This explanation
├── archived_scripts/       <- Historical phase-specific audit and experiment scripts
├── old_reports/            <- Intermediate developmental and exploratory reports
├── debug/                  <- Diagnostic scratch scripts used during development
└── old_experiments/        <- Deprecated exploratory experiment logs
```
